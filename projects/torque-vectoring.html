4WD EV Racecar Torque-Vectoring Control

A yaw-moment controller distributes torque across four independently driven wheels.

NTHU Racing TH07 · 2023–2024 · C/C++ · Vehicle dynamics · Track testing

View project slides ↗Watch team video ↗

The project

I developed a yaw-moment-based control strategy using steering, wheel-speed, and IMU yaw-rate signals, then implemented it in the vehicle ECU for track testing.

How it works

  1. Use a vehicle model and tire behavior to define a reference yaw response.
  2. Combine sensed state with the requested yaw moment to allocate wheel torques.
  3. Validate the logic in simulation, then test it on the racecar with driver-selectable mapping and safety interlocks.
