IMU Orientation Tracking & Panorama Reconstruction

Sensing & Estimation in Robotics, UC San Diego, Feb 2026
Project Report  /  Code
Python PyTorch Sensor Fusion Gradient Descent Quaternions / SO(3) Computer Vision

In this project, I developed a complete pipeline to recover accurate roll, pitch, and yaw angles from IMU measurements and construct high-quality panoramas. By formulating the orientation tracking as a gradient-descent optimization problem, the system effectively mitigates sensor noise and gyroscope drift.

Key Technical Implementations

  • Motion & Observation Models: Defined a motion model via gyroscope integration to estimate orientation trajectories. Created an observation model based on accelerometer data to align with the gravity direction, preventing long-term drift.
  • Trajectory Optimization (PyTorch): Formulated a cost function mapping relative rotation errors to a 3D rotation-vector (Lie algebra). Utilized torch.autograd for automatic differentiation to perform projected gradient descent on the unit-quaternion manifold.
  • Performance Validation: Compared optimized quaternion trajectories against Vicon motion-capture ground-truth data, evaluating roll and pitch trajectories against Vicon motion-capture ground truth.
  • Panorama Reconstruction: Transformed world-frame poses to the camera frame, mapped RGB image pixels to spherical coordinates, and projected them onto a cylindrical panorama to stitch continuous 2D environments.

4WD EV Racecar Torque-Vectoring Control

NTHURacing TH07, National Tsing Hua University
Project Page  /  Video
C/C++ MATLAB/Simulink Sensor Fusion Control Systems Pacejka Tire Model Vehicle Dynamics

Developed and deployed a real-time torque-vectoring controller to fully utilize the independent 4-wheel drive electric motors on the TH07 racecar. The system continuously monitors vehicle states and actively distributes torque to maximize cornering capability and overall vehicle stability.

Key Technical Achievements

  • Algorithm Design & Control Strategy: Developed a yaw-moment-based torque-vectoring controller. Leveraged a bicycle model and integrated a Pacejka tire model to generate the reference yaw rate and compute optimal wheel torque allocations.
  • Sensor Fusion & Real-Time Deployment: Fused data from the IMU (yaw rate), steering angle sensor, and ground-speed sensor. Successfully implemented the algorithm in C/C++ on the vehicle's central ECU, achieving a highly responsive ~1 kHz control loop.
  • Simulation & SIL Testing: Built comprehensive vehicle dynamic models in MATLAB/Simulink to simulate full-car behavior and validate the control logic (Software-in-the-Loop) prior to physical track testing.
  • Track Performance: The controller allowed for driver-selectable mapping and included rigorous safety interlocks. It was deployed for track testing; the team placed P4 in Acceleration and P5 in Skidpad at Formula Student Czech 2023.

Nonlinearity Modification of CMOS-MEMS Resonators

National Tsing Hua University / 2024
Project Paper
CMOS-MEMS TSMC 0.35 µm Wet Etching Network Analyzer Nonlinear Dynamics FEM Simulation

This paper presents an experimental study addressing a critical performance bottleneck in miniaturized sensors: the limited power handling capabilities of MEMS resonators caused by amplitude-to-phase modulation (AM-PM) noise from nonlinear vibration.

Key Technical Achievements

  • Structural Design: Integrated small coupling springs at the ends of cantilever and fixed-fixed beam structures. These springs act as stress concentration features, storing more tension under high excitation to counter negative capacitive nonlinearity.
  • Microfabrication: Developed and released the devices utilizing the industry-standard TSMC 0.35 µm CMOS process, followed by a precise sulfuric acid (H₂SO₄) wet-etching process to remove sacrificial metals and suspend the micro-beam structures.
  • High-Frequency Measurement: Conducted precise S-parameter measurements using a 4-Port Network Analyzer inside a customized vacuum chamber to effectively eliminate air damping and squeeze-film effects.
  • Dynamic Tuning Results: Successfully proved that modifying cantilever beams with shorter springs mitigated softening nonlinearity (achieving a more linear response), while fixed-fixed beams exhibited enhanced hardening nonlinearity.

LiDAR-Based SLAM & Mapping

Sensing & Estimation in Robotics, UC San Diego, Feb 2026
Project Report  /  Code
Python LiDAR ICP Algorithm GTSAM Bresenham's Algorithm

In this project, I built a robust 2D Simultaneous Localization and Mapping (SLAM) pipeline entirely from scratch. The system fuses raw LiDAR point clouds with robot odometry to solve the classic "chicken-and-egg" problem of mapping an unknown environment while simultaneously keeping track of the robot's location within it.

Key Technical Implementations

  • Front-End Scan Matching (ICP): Implemented the Iterative Closest Point (ICP) algorithm to align sequential LiDAR scans.
  • Occupancy Grid Mapping: Developed a mapping module that utilizes Bresenham's line-drawing algorithm for ray tracing.
  • Back-End Trajectory Optimization (GTSAM): Corrected drift by formulating the trajectory as a factor graph, using GTSAM for robust pose-graph optimization and loop closure.
